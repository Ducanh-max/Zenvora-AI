# Zenvora AI
Nền tảng học tiếng Anh tương tác được xây dựng mới bằng Next.js, React và Supabase.

## Chạy local
1. Cài Node.js 20.9 trở lên.
2. Chạy npm install.
3. Sao chép .env.example thành .env.local và điền URL + publishable key từ Supabase project riêng của Zenvora AI.
4. Chạy npm run dev.

Không commit .env.local hoặc secret key.
