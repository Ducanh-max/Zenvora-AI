# Ảnh bìa khóa học AUNORA

Đặt ảnh khóa học vào thư mục này. Dùng ảnh dọc tỷ lệ khoảng 3:5 hoặc 2:3 (ví dụ 800×1200 px), định dạng .webp hoặc .png.

Tên file gợi ý theo 10 khóa:

1. english-starter.webp
2. everyday-english.webp
3. english-for-travel.webp
4. grammar-in-action.webp
5. confident-conversations.webp
6. advanced-vocabulary-builder.webp
7. phrasal-verbs-mastery.webp
8. idioms-and-expressions.webp
9. academic-vocabulary-quest.webp
10. real-world-vocabulary.webp

Các ảnh phải được thêm qua GitHub, sau đó mới có thể hiển thị trên website. Không xóa README.md nếu muốn giữ thư mục khi chưa có ảnh.
